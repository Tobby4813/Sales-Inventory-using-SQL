Sales & Inventory Management System (SQL)
Overview
This project, developed by Olaleye Tobiloba for Golden Palms Retail Ltd. focuses on designing and implementing a Sales and Inventory Management System using SQL. The system models customers, suppliers, products, orders, and payments, enabling efficient data organization, accurate reporting, and actionable business insights.

Objectives
* Build a relational database for sales and inventory management.

* Define tables and relationships using primary/foreign keys.

* Store and manage customer, product, supplier, order, and payment data.

* Execute SQL queries for analysis and reporting.

* Identify sales trends and customer purchasing patterns.

Dataset
Total records: 220 rows across multiple tables

Tables: Customers (20), Suppliers (10), Products (30), Orders (45), Order Details (70), Payments (45)

Structured as a relational database with key attributes like customer_id, product_id, order_id, order_date, quantity, amount, and payment_method.

Tools Used
MySQL – Database creation, queries, and analysis

Microsoft Excel – Data inspection and preparation

ChatGPT – Assisted in generating realistic dataset records and SQL queries

Methodology
Requirement Analysis – Identified challenges in sales tracking, inventory, and reporting.

Database Design – Built ER model with defined relationships.

Database Creation – Implemented schema using SQL DDL commands.

Data Population – Inserted realistic records via SQL.

Data Analysis – Ran queries to uncover insights (best-selling products, customer behavior, supplier performance, inventory levels).

Testing & Validation – Verified accuracy of queries and reports.

Results
Accurate tracking of customer purchase history.

Identification of best-selling and slow-moving products.

Reliable sales and inventory reports for decision-making.

Improved supplier monitoring and procurement records.

Revenue analysis across different periods.

Challenges
Writing complex queries with multiple JOINs and subqueries.

Debugging syntax and logical errors.

Optimizing query performance on larger datasets.

Ensuring correct relationships between tables.

Conclusion
The project successfully delivered a functional relational database with comprehensive SQL queries for operational and analytical reporting. It provides a reusable foundation for retail businesses, supporting insights such as order summaries, loyal customers, restock recommendations, and supplier performance.
